## 宝贝学习乐园（5 岁儿童学习工作台）

**产物**：`baby-learning/index.html`（单文件，约 75KB，零外链）
**线上**：https://6ae5427ab21b4fd0b9ef585240bd3f85.bj6.agentos-app.net

### 需求与实现
用户要求 5 个模块（超出常规 3-4 个上限），因字母/古诗属内容展示型、复杂度可控，一次性做全：
1. 字母乐园：26 字母卡片 + Web Speech API 英文发音 + 大小写配对游戏
2. 古诗花园：8 首幼儿古诗，`<ruby>/<rt>` 标注拼音，逐句 / 整首朗读（zh-CN）
3. 数字王国：0-20 认知（中英双读）+ 10 以内加减法 + 数数游戏
4. 逻辑挑战：图形循环找规律 / 找不同 / 数字规律 / 比大小，4 选项
5. 闯关冒险：5 关 × 5 题（字母/数字/古诗/逻辑/混合）+ 3 星评级 + 12 枚徽章墙

### 关键技术决策
- localStorage 单 key `wb_baby_data_v1` 存整个 DB 对象，实测仅 ~700 bytes，避免多 key 管理成本
- Web Speech API 兼容：`onvoiceschanged` 异步补齐 voices；iOS 需用户手势解锁，首次 touchstart/click 播放静音 utterance 唤醒引擎
- 今日任务顺延：`rollTasks()` 比对 `DB.tasks.date`，跨天时把未完成项标 `late=true` 并红色提示，另有 60s 定时器处理"跨零点仍开着页面"的情况
- 图形题干扰项必须形状互不相同（初版会出现同形状不同色，对幼儿有歧义，已修）
- 儿童向按钮 ≥50px（超出常规 44px 要求）

### 验证方法（可复用）
写了 `_devtest/_smoke.js`：手搓最小 DOM mock（getElementById 返回 stub 元素、setTimeout 改同步执行以暴露延迟回调错误），把 script 标签内容 eval 后空跑全部交互。
批量校验断言：算术 200 题（不超 10、不出负数、答案在选项内）、逻辑 300 题（正确答案唯一）、闯关 5 关全通 + 全错分支、跨天顺延标记数、localStorage 持久化。
这套方法对"单文件 HTML 工作台"很有效，能在部署前抓出运行时异常。

### 踩坑
- `rm` 删除文件时 genie-trash 报 "relative path rejected"，改用 `mv` 移到别的目录规避
- `curl -o /tmp/xxx` 在 Git Bash 下 exit 23，改用工作区内相对路径正常
