## 技术说明（重要）
用户要求"微信小程序全套 wxml/wxss/js/json + 云数据库"。真小程序需微信开发者工具、AppID、云开发环境审批，无法在本环境"部署+扫码即用"。
因此沿用线上「宝贝学习乐园」相同、可立即扫码可用的技术栈：**单文件 HTML 工作台**，localStorage 当实时同步数据库，全部动画用内联 SVG/CSS 手写，零外部依赖、断网可玩。

## 五大作业模块
- **字母乐园**：26 张字母卡点击发音（Web Speech API）朗读 "Apple. 苹果"——**只读英文单词**（不再带字母前缀），读完英文停顿 **2 秒**再读中文；**已删除大小写配对游戏**（只保留认字母）
- **古诗花园**：每日随机 5 首经典幼儿古诗（带拼音、点击朗读），**左右布局：左边古诗居中、右边分页显示「古诗含义」译文（上一首/下一首 + 页码），点读整首后才解锁「我会背了」**
- **数字王国**：0–100 随机数字认知（每日 10 个，点击**中英双语**朗读——先读中文、停顿 **2 秒**再读英文，语速适中）；20 以内加减法随机 **8 题**，答对更新下一题、**答错弹窗+语音"你答错啦，继续加油哦"**；**8 题做完自动完成数字王国今日打卡并跳转逻辑挑战**；**已删除数数小游戏**
- **逻辑挑战**：**找规律 / 图形配对 / 排序题 / 专注力训练（视觉抗干扰）** 四类题型，每题 **4 个选项**，每日随机出题；**答对满 8 题自动完成今日打卡并跳转闯关冒险**
- **闯关冒险**：综合出题闯关 + 金币奖励 + **成就徽章墙（共 24 个成就）**

## 设置模块（家长专属，本轮新增）
**进入方式**：底部第 4 栏「设置」→ 弹出家长验证（随机两位数乘法算式），答对才放行；本次会话内只需验证一次，切走再回来不用重复算。

**四大功能**
1. **打卡内容管理**：增 / 删 / 改自定义打卡项——名称、分值（完成奖励几个爱心）、分类（生活习惯 / 学习 / 运动 / 其他）。配置好的项会出现在「今日计划」底部，孩子点一下即打卡加爱心，同一天不能重复领。
2. **奖励管理**：增 / 删 / 改实体奖励——名称、所需爱心值。孩子在「我的农场 → 🎁 爱心奖励」用爱心兑换，兑换成功扣爱心并记入奖状墙。
3. **萌可昵称修改**：默认「优雅萌可」，可改成宝宝喜欢的名字（最多 12 字），农场页标题、喂食/洗澡/摸头提示全部同步。
4. **数据管理**：导出 JSON 备份 / 导入恢复 / 清空全部数据（二次确认，清空后保留家长的设置配置）。原来放在顶栏的这三个按钮已收进设置里，顶栏只留一个「设置（家长）」入口。

## 作业↔农场联动（核心）
**奖励**
- 单个模块完成 → +1 阳光 + 1 颗学科专属种子（字母乐园=爱心 / 古诗花园=勇气 / 数字王国=希望 / 逻辑挑战=知识 / 闯关冒险=光明）
- 每个细分打卡项完成 → +2 爱心（替代旧版米粒）
- 5 个模块全部完成 → 累计 5 阳光 + 5 颗学科种子

**惩罚（没写作业→农场受罚，重点）**
- 当晚跨天结算（`App.rollDay`）：n = 未完成模块数
- 1 个没写 → 1 只小狗熊啃当天作物，健康 −1
- 2 个没写 → 2 只熊毁掉半株成熟植物（成熟作物降一级；无成熟则枯萎 1 株）
- 3 个及以上没写 → 3 只熊（上限），成熟作物全部枯萎 + 当天禁止收获（f.noHarvest=true）
- 护盾（连续打卡 3 天兑换）可挡一次熊

**修复**
- 补完未完成作业 → 领 1 瓶杀虫剂，清除小狗熊 + 恢复植物健康 + 解除禁止收获

**种植**
- 浇水（带浇水动画）升作物等级 → 成熟后收获金币；金币商城买爱心 / 肥皂 / 奖状 / 头像框 / 皮肤 / 自定义实体奖励（按钮可改名称与花费）

## 养宠物：优雅萌可（农场页功能入口，带动态动画）
- **入口位置**：优雅萌可就在「我的农场」页面顶部，是农场页的核心互动功能（喂食 / 洗澡 / 拍拍头）
- **动态动画**（纯 CSS keyframes，零外部依赖）：身体上下浮动 + 眨眼 + 小翅膀扇动 + 头顶星光闪烁 + 卡片粉色光晕呼吸；拍拍头时触发"说话"弹跳动画
- **形象说明**：原创 Q 版优雅萌可（粉色身体 + 优雅蝴蝶结 + 会飞的小翅膀 + 星星），受奇妙萌可风格启发但为原创绘制，避免直接照搬受版权保护的角色造型
- 喂食：10 爱心 → 饱食 +30%，12h 衰减
- 洗澡：1 块肥皂 → 清洁拉满，24h 衰减
- 拍拍头：显示"萌可开心的叫了一声 💖"并用语音念"优优"
- 饿倒气泡："我好饿呀 优优，小主人，快给我喂食吧！"（点击朗读）
- 金币商店：买萌可爱心（5 金币=10 个）、肥皂（5 金币=1 块）

## 种子图鉴（农场页 + 道具商店，按模块锁定解锁）
- 5 类专属种子严格对应模块：**字母乐园=爱心种子 / 古诗花园=勇气种子 / 数字王国=希望种子 / 逻辑挑战=知识种子 / 闯关冒险=光明种子**
